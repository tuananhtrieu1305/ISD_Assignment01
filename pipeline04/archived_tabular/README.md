- `pipeline04/diabetes_pipeline04.ipynb`
- `pipeline04/house_price_pipeline04.ipynb`
- `pipeline04/customer_behavior_pipeline04.ipynb`

No Assignment 03 notebooks or datasets are modified by this archive marker.

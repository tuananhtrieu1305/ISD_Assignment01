# Web project01 — chuẩn bị cho Phase 2

`frontend/`: React dùng style tiểu luận3, bốn khu câu hỏi/hồ sơ, kết quả/nguồn, trace và so sánh.

`backend/`: Python CPU; code export từ notebook hiện hành, có source parity và artifact checks. Không lấy serving archive cũ rồi nhận là đã chạy code agent mới.

`deploy/`: requirements/config Render và hướng dẫn packaging sẽ làm Phase 2. Chưa có web/API chạy được trong Phase 1; không deploy.

# Dataset cards

Phase 1 khóa 8 dataset instance dùng trong ba chương thực nghiệm:

| Chương | Dataset cards |
|---|---|
| 2 — ML cơ bản | `ch2_diabetes_binary.md`, `ch2_vietnam_housing.md`, `ch2_ecommerce_behavior.md` |
| 3 — CNN | `ch3_eurosat_rgb.md`, `ch3_oxford_pets.md`, `ch3_diabetes_012.md` |
| 4 — RNN | `ch4_online_retail_ii.md`, `ch4_aapl.md` |

Mỗi card có: link/citation/license status, local provenance/hash, kích thước vật lý và logic, phân bố, mẫu input/output, preprocessing/split, nhận xét và giới hạn. Nếu card và raw artifact mâu thuẫn, raw artifact + hash và notebook audit là nguồn quyết định; sai lệch phải được ghi trong card, không sửa im lặng.

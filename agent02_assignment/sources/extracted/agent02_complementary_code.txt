1 Overview
The AGENT02 program implements and compares two agent types:
1. A reinforcement-learning-based agent using tabular Q-learning.
2. A rule-based agent using a predefined conditional policy.
Both agents interact with a simulated e-commerce environment. The RL agent learns action
values from rewards, whereas the rule-based agent follows a fixed decision policy.
The program supports the following experiments:
• Baseline training and evaluation.
• Comparison of learning rates.
• Comparison of exploration schedules.
• Evaluation across multiple random seeds.
• Export of CSV files, a learned Q-table, and figures.

3 Mathematical Model
3.1 State and action
For agenti, the local state is
si(t) = (dt,c i(t)),
where dt∈{ 0, 1} is the demand level andci(t)∈{ 0, 1} is the competitor’s previous action.
The action space is
A ={0, 1},
where action 0 means no discount and action1 means offering a discount.
Each agent has four possible states and two possible actions. The Q-table therefore contains
eight entries.

3.2 Reward
The simulated conversion probability is
pi(t) = clip (0.30 + 0.25dt + 0.15ai(t)− 0.10a−i(t), 0.05, 0.95).
The number of sales follows
Si(t)∼ Binomial(Nt,p i(t)),
where Nt = 10 for low demand andNt = 20 for high demand.
With priceP = 10, unit costC = 5, and discount rateδ = 0.20, the reward is
ri(t) = Si(t) [P (1−δai(t))−C].
This is a simplified teaching model. Its assumptions should not be interpreted as an empirically
validated model of real e-commerce markets.
3.3 Q-learning
The RL agent updates its action-value estimate according to
Q(st,a t)←Q(st,a t)
+α
[
rt +γ maxa′ Q(st+1,a′)−Q(st,a t)
]
.
Here, α is the learning rate andγ is the discount factor.
The RL policy uses anε-greedy strategy during training. During the separate evaluation phase,
the learned policy acts greedily and its Q-table is not updated.

7 Output Interpretation
7.1 A verage reward
ForT evaluation steps, the average reward is
Ri = 1T T∑t=1ri(t).
A larger value indicates greater simulated profit per time step under the specified environment
and evaluation protocol.
It does not establish that the agent will perform better in a real marketplace or under a different
environment.
7.2 Action frequency
The discount action rate is
ρi = number of discount actionstotal number of actions .
A larger discount rate does not necessarily imply greater profit. The discount increases the
conversion probability in the model but reduces the profit margin per sale.
7.3 Q-table
The Q-table stores the learned action values for each state. The greedy policy chooses the action
with the largest estimated value.
Students should inspect the table and explain how its entries determine the learned policy.

8 Reproducibility and Limitations
The program specifies random seeds and records parameter configurations. Reproducibility also
depends on the software environment and the consistency of the evaluation protocol.
The following limitations must be considered:
1. The market has only two demand states and two actions.
2. The conversion-probability equation is illustrative.
3. Demand evolves independently of the agents’ actions.
4. The RL agent is trained against a fixed rule-based opponent rather than another simulta-
neously learning agent.
5. A tabular method does not scale directly to large, continuous state spaces.
6. The model does not include inventory, customer heterogeneity, operating costs beyond
unit cost, or long-term customer relationships.
These limitations are appropriate for an introductory laboratory but should be addressed before
using the model for applied economic conclusions.

10 Conclusion
This implementation provides a reproducible starting point for studying the difference between
learning-based and rule-based decision-making in a multi-agent environment.
The RL agent estimates action values from reward feedback. The rule-based agent follows
a predefined policy. The experimental framework supports comparisons of rewards, action
frequencies, learning rates, exploration schedules, and variability across random seeds.
The scientific objective is to interpret the results carefully, identify the assumptions that influence
them, and determine which conclusions are justified by the experiments.

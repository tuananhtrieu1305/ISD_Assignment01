Intelligent System Development Laboratory Experiment 02
1 Objectives
The purpose of this laboratory experiment is to understand, implement, and experimentally
compare two approaches to intelligent agent design:
1. Reinforcement-learning-based agents.
2. Rule-based agents.
After completing this experiment, students should be able to:
1. Explain the concepts of an agent, environment, state, action, reward, and policy.
2. Implement a simple reinforcement-learning agent using tabular Q-learning.
3. Implement a rule-based agent using conditional statements.
4. Design a small multi-agent simulation.
5. Collect, visualize, and interpret experimental data.
6. Compare agents using consistent performance metrics.
7. Explain the limitations of learning-based and rule-based decision-making.
2 Problem Description
Consider a simplified e-commerce marketplace in which two agents sell similar products. Each
agent must decide whether to offer a discount to customers.
The agents interact with a shared environment. Customer demand may be low or high, and
each agent can observe whether its competitor offered a discount in the previous time step.
The available actions are:
• Action 0: Do not offer a discount.
• Action 1: Offer a discount.
The objective is to obtain a high cumulative profit while responding to changing demand and
competitor behavior.
We investigate two different ways to make decisions.
2.1 Agent A: Reinforcement-learning-based agent
The reinforcement-learning (RL) agent learns from experience. It observes a state, selects an
action, receives a reward, and updates its estimate of the value of that action.
In this experiment, the agent uses tabular Q-learning.

2.2 Agent B: Rule-based agent
The rule-based agent follows a predefined decision policy. For example, it may avoid discounts
when demand is low and match a competitor’s discount when demand is high.
Its behavior is determined by manually specified rules rather than a learning algorithm.
Important distinction: A rule-based agent does not automatically learn from rewards. An
RL-based agent uses experience and rewards to update its action-value estimates.

4 Method 1: Q-Learning Agent
4.1 Action-value function
The RL agent maintains a Q-table:
Q :S×A−→ R.
For each state-action pair,Q(s,a ) estimates the expected discounted return obtained by taking
action a in states and subsequently following the learned policy.
The agent has four states and two actions. Therefore, its Q-table contains eight action-value
entries.

4.4 Algorithm
1. Initialize the Q-table to zero.
2. Reset the environment and observe each agent’s state.
3. Select an action using theε-greedy policy.
4. Execute both agents’ actions simultaneously.
5. Observe rewards and next states.
6. Update each agent’s Q-table.
7. Repeat for the specified number of steps.
8. Evaluate the learned policies after training.

5 Method 2: Rule-Based Agent
The rule-based agent does not maintain a Q-table. Its action is determined directly by the

The corresponding rules are:
1. If demand is low, do not offer a discount.
2. If demand is high and the competitor previously offered a discount, offer a discount.
3. If demand is high and the competitor did not previously offer a discount, do not offer a
discount.
These rules are manually designed. They do not necessarily maximize profit.
A rule-based system may perform well when its rules match the environment. However, when
conditions change, the rules may need to be redesigned by a developer.

9 Discussion and Interpretation
Inadditiontoansweringthequestions, thereportshoulddiscussthefollowinggeneralobservations
where relevant:
• A rule-based agent can make consistent decisions, but its performance depends on the
quality of its rules.
• An RL-based agent can improve its decisions through feedback, but learning does not
guarantee an optimal policy.
• Random demand and stochastic sales can cause reward variation even when the policy
remains unchanged.
• Two simultaneously learning agents can influence each other’s observed outcomes.
• Training performance and evaluation performance measure different aspects of an agent.
Students should distinguish observations from explanations. For example, a higher measured
reward is an observation; the claim that a particular learning mechanism caused the improvement
requires further evidence.

12 Conclusion

RL-based agent learns action values from reward feedback, whereas the rule-based agent follows
an explicitly designed policy.
